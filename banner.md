# Banner

<figure><img src=".gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

The Banner logo gives your homepage a fresh and modern look with the big logo on the top and a minimal layout.

In this article, we will show you how to add a Banner logo section.

<figure><img src=".gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>

### How to edit a Banner logo **section** <a href="#how-to-edit-a-banner-logo-section" id="how-to-edit-a-banner-logo-section"></a>

#### Section settings <a href="#section-settings" id="section-settings"></a>

**Background settings**

Add a background image for the Banner logo section. You can add an image for desktop and mobile view separately (**Desktop image** and **Mobile image**).

Set the **Image overlay opacity** to the image if needed.

#### Block settings <a href="#block-settings" id="block-settings"></a>

In the **Banner logo** section, you can add 4 different blocks: **Subheading**, **Heading**, **Text,** and **Button.**
