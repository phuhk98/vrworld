# Partner

<figure><img src=".gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>

The VR Partners section is designed to showcase key brands, partners, or vendors that your store collaborates with. By displaying recognized industry logos, this section helps build trust with visitors, highlights the quality of your catalog, and improves navigation by providing a clear brand showcase.

<figure><img src=".gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure>

### Step-by-Step Customization Guide

Use the sidebar panel on the right side of the Theme Editor to customize the content, typography, layout, and slider behavior for this section.

#### 1. Color Scheme & Styling

* Color scheme: Select from pre-configured theme color palettes to match the section background with your site’s aesthetic.
* Edit scheme: Click the link below the presets to fine-tune specific color values (background, text, accent colors).

#### 2. Heading Settings

* Heading text: Enter your main title in the text box (e.g., _"Discover the Best in VR Top-Rated Brands"_). You can apply formatting like Bold, _Italic_, or insert hyper-links.
* Heading size: Adjust the visual scale of the title using the dropdown menu (e.g., _Small_, _Medium_, _Large_).

#### 3. Description Settings

* Description text: Use the rich text editor to add contextual subtext beneath the main title. You can format text, add bullet points, or insert links as needed.
* Alignment (Desktop & Mobile): Choose how text is aligned (_Left_, _Center_, or _Right_) independently for desktop screens and mobile devices to ensure responsiveness.

#### 4. Slider & Layout Options

* Columns: Drag the slider to set how many brand logos appear per row on desktop (currently set to 6).
* Infinite loop: Enable this toggle to let the slider loop continuously back to the first item when scrolling.
* Auto-rotate slides: Enable this toggle to automatically cycle through brand logos without requiring user interaction.
* Change slides timer: Adjust how long (in seconds) each slide displays before rotating automatically (currently set to 5 seconds).
