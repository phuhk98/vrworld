# How do i set collection info?

There are 2 layouts to show the collection information

**Collection with slider**

With this layout, your collection name will scroll.

Add collections to the **Collections list** to display a row of collections below the scrolling collection.

Active **Show description** if you want to show the collection description above the scrolling collection.

<figure><img src="../.gitbook/assets/image (52).png" alt=""><figcaption></figcaption></figure>

**Collection with list**

Dynamic active **Show heading/ Show description**/ **Show collection** list in this layout.

<figure><img src="../.gitbook/assets/image (53).png" alt=""><figcaption></figcaption></figure>

To add a description for each collection, edit the collection detail.
