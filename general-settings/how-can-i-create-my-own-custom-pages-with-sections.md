# How can I create my own custom pages with sections?

All of our themes come with a default page template and a set of predefined page templates that you can use to get started. This default template is what resources use if you don’t have an alternate template explicitly set.

Any changes you make to a template will impact all pages that use that template. If you want to display some pages of a particular template differently, then you can create a new template based on one that already exists in your theme.

In order to create a new page, you click on _Pages_ -> _Create template_, then set **Name** and template **Based on** for the page
