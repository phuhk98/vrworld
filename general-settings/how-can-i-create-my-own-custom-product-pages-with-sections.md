# How can I create my own custom product pages with sections?

All of our themes come with a default product template and a set of predefined product templates that you can use to get started. This default template is what resources use if you don’t have an alternate template explicitly set.

Any changes you make to a template will impact all products that use that template. If you want to display some product content differently, with their own unique content, then you can create a new template and assign it to those products to use.\
\
In order to create a new page, you click on _Products_ -> _Create template_, then set **Name** and template **Based on** for the product page.
