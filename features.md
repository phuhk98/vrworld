The VR Features section displays key value propositions, store policies, or benefits (such as Free Shipping, 24/7 Support, Money-back guarantees, or Discounts) in a clean, multi-column layout. Adding these visual trust badges helps build customer confidence, reduce purchase hesitation, and improve conversion rates right before users reach the footer or checkout.

### Step-by-Step Customization Guide

Click on an individual Feature Item block (e.g., _Feature Item – Free Shipping_) under the VR Features section on the left sidebar to edit its settings in the right-hand panel.

#### 1. Icon Image Settings

*   Icon image: Upload or select an icon file (e.g., `ship.svg`).

    > Tip: For best visual quality and scaling, use transparent PNG or vector SVG icons.

#### 2. Text & Description Content

* Title: Enter the primary headline for the feature card (e.g., _"Free Shipping"_). Keep it short and impactful.
* Description: Add supporting text below the title using the rich-text editor (e.g., _"Enjoy free shipping on all orders."_). You can format text with Bold, _Italic_, or insert links if needed.

#### 3. Adding or Removing Feature Items

* Add Feature Item: Click the + Add Feature Item button in the left panel to insert additional benefit cards (up to your theme's maximum limit).
* Remove block: Click the Remove block option (with the red trash icon) at the bottom of the right panel to delete an unwanted feature card.
