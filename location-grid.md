# Location grid

The Location grid section is designed to display multiple store or service locations in a clear, organized grid layout. Each grid block can feature a location name, address, contact details, hours of operation, or even a map image, making it easy for customers to find the most convenient place to visit.

**Configure your Location grid section:**

Add a **Caption** to communicate the key message alongside the visual content

Enter the **Heading** text to display inside the section

Use the **Heading size** options to set the section’s heading text&#x20;

**Columns**

Use the **Color scheme** picker to select a color scheme for each column.

**Alignment** shows text content on the left, center, or right side. On mobile, content is always left.

**Number of columns on desktop**: The maximum number of items per row, upper 4 columns

On a mobile screen, the content can display in 2 layouts: List and Scroll.

**Configure a block for your Location grid section**

Each blog has an **Image** to describe more content.

2 content options: **Content left** and **Content right** to show information. Format the text and add links using the Text editor pane.
