# How to set up Mega menu

The Unity theme has 3 types of data sources to show the Mega menu: Navigation, Products, and Collections.

<figure><img src="../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>

**Navigation**

1. To show mega menu layouts, create a multi-level dropdown menu first.



<figure><img src="../.gitbook/assets/image (66).png" alt=""><figcaption></figcaption></figure>

2\. From your Shopify admin, go to **Online Store** -> **Themes**.

3\. Find the theme you want to edit, then click **Customize**.

4\. In the **Header** section on the left editor window -> Add a Mega menu block

5\. Set up the Mega menu

* Add parent item: item name to apply a mega navigation dropdown
* Select data source: Navigation
* Select the navigation for your mega menu created
* Add an image and an image link to highlight a collection or a product.
