# Blog Post

<figure><img src=".gitbook/assets/image (16).png" alt=""><figcaption></figcaption></figure>

Blog Post display your latest or featured blog articles in a visually engaging collage-style layout. Instead of a simple list, this section presents posts using a dynamic grid that combines images, titles, excerpts, and links, giving your store a magazine-like feel.

**Blog:** Select a blog to display.

**Maximum items to show**: The maximum number of posts to display in this section.

Add a **Caption** to communicate the key message alongside the visual content

Enter the **Heading** text to display inside the section

Use the **Heading size** options to set the section’s heading text&#x20;

In the **Butto**n **Label** text box, enter text to display as a button label text inside the section.

In the **Link** box, enter a URL or select a store page to link to. The section’s button uses the link.

**Post card**

Set **Color scheme** for the article

Select the Number of heading lines to show in each blog card

Show or hide the option of content: Date, Blog, Comment, Author, and Read more icon.
