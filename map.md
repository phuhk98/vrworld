# Map

The Map section makes it easy for customers to find your physical store, office, or service location directly on your website. By embedding an interactive map, you provide clear direction and improve accessibility, helping visitors connect with you offline.

**Configure your Map section**

Add an **Image** to show your location view.

**Location**

Dynamic Show/hide information, when you hide information, only show the hotspot.

**Horizontal/Vertical position**: set the location point on the image

An **Image** to describe more for your location.

2 content options: **Content left** and **Content right** to show location information. Format the text and add links using the Text editor pane.
