# Image spotlight

The Image Spotlight section is designed to draw attention to a single impactful image or a set of featured visuals, allowing you to highlight products, campaigns, or brand stories in a bold and focused way. It’s perfect for showcasing high-quality lifestyle photography, promotional graphics, or hero visuals that deserve the spotlight.

**Configure a block for your Image spotlight section**

\
**Image hotspot color**: Custom color for the Image hotspot color.

Enter the **Heading** text to display inside the section

Use the **Heading size** options to set the section’s heading text&#x20;

In the **Description** box, enter text to display inside the section. Format the text and add links, using the Text editor pane.

**Horizontal/Vertical position**: set the product position point on the image
